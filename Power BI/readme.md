# Power BI Dashboard: Beverage Brand Sales & Profit Analysis

## Overview
This Power BI project visualizes and analyzes sales and operating profit data for a Beverage Brand. It is designed for interactive use, providing insights into brand performance, area-specific sales, and key factors influencing profitability.

---

## Features

- **Data Loading**  
  Loaded relevant data from the desired source (database/Excel/CSV).

- **Dashboard Naming**  
  Created a dedicated dashboard titled **"Beverage Brand Sales & Profit Analysis"**.

- **Date Slicer**  
  Implemented a Date Slicer to allow users to interactively filter data by specific dates.

- **Q&A Visual**  
  Added a Q&A section to help new users quickly understand key metrics and ask natural language questions.

- **Key Influencers Visual**  
  Utilized the Key Influencers visual to explain Operating Profit by Beverage Brand.
  - **Findings:**  
    - Increase of the beverage brand operating profit  
    - Decrease of the beverage brand operating profit
  - **Focus Mode:** Clicking on Focus Mode provides an expanded, explainable chart for deeper insights.

- **Map Visualization**  
  Visualized total sales by geographical location using a map, formatted for better readability and user interaction.

- **KPI Visual**  
  Created a KPI card to track:
  - Profit
  - Sales Amount

- **Matrix Visualization**  
  Built a matrix to display:
  - Units Sold
  - Price per Unit
  - Total Sales
  - Operating Profit
  - Operating Margin

- **State-wise Map Visualization**  
  Displayed sold units across different states to provide a regional sales overview.
