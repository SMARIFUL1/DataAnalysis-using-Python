# Data Modeling for Analytical Scenarios

This project sets up a structured data model to support analytical and reporting use cases.

## Key Components

- **Table Setup**: Define fact and dimension tables.
- **Relationships**: Establish clear connections between tables.
- **Calculations**: Build measures and KPIs to enable insights.
- **Access Management**: Control user permissions and data visibility.

## Schema Design

I follow a **Star Schema** structure:

- **Fact Tables**: Contain measurable, quantitative data (e.g., sales, revenue, transactions).
- **Dimension Tables**: Store descriptive attributes related to fact data (e.g., customer, product, time).
